# Community listing

Pilot Starting Balance is a free, VA-agnostic phpVMS 7 module for
administrator-controlled pilot credits.

Administrators can set a default amount that is applied once when a new pilot
confirms their email, and can issue a one-off amount to multiple pilots whose
current balance is zero. All credits use the phpVMS finance journal and the
module prevents duplicate registration credits.

The module includes an admin status page with a cached GitHub release checker.
Updates are manual and administrator-controlled. No phpVMS core files need to
be edited.
